SCHEDULE & PROTECTION

Backup settings

Server delivery

FTPS requires a valid TLS certificate and passive FTP access. Connection test only checks login and an existing folder; a real backup creates the configured folder if needed.

Email delivery

Use your provider's supported SMTP login or app password. TLS is required. Large attachments can exceed the provider limit; the local/server backup stays available. An uncertain send is never resent automatically.

Daily backups can be saved locally on the server without FTP or email delivery. Saved credentials are encrypted on the server. Backup files are retained; this feature does not delete old local or remote files. Manual backups work even when the daily schedule is disabled.

BACKUP HISTORY

Local, server and email results

Failed destinations retry up to three total attempts for the daily job. Manual retry reuses the same file and skips successful destinations. SMTP acceptance is not proof of inbox delivery.
